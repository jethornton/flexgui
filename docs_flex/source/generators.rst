==================
NC Code Generators
==================

Bolt Circle Generator
---------------------

A Bolt Circle NC Code Generator can be added to your GUI by adding either a
QWidget or QFrame and setting the object name to `bc_gen`.

.. image:: /images/bc-gen-01.png
   :align: center

* Units can be Metric or Imperial
* Drill Cycle can be Normal or Peck
* Start Angle 0 is to the right of center and increases CCW
